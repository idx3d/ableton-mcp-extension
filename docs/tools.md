# MCP Tool Reference

> Generated by `npm run gen:tools` from the tool registry — do not edit by hand.

22 tools.

## get_set

Compact overview of the open Live set: tempo, scale, tracks (one line each: id, name, type, devices, clip count) and scenes. Call this first to obtain IDs; drill down with get_track / get_clip. Includes arrangement cue points (cues) when present.

**Parameters:** none

## get_track

One track in depth: its clip slots per scene (with clip summaries) and device chain. Use the trackId from get_set.

**Parameters:** `trackId`

## get_clip

Full detail of one clip, including its MIDI notes as compact tuples [pitch, startBeat, durationBeats, velocity, extras?].

**Parameters:** `clipId`

## update_song

Update song-level settings in one undo step: tempo (20-999 BPM) and arrangement cue points. addCues creates locators at beat positions; renameCues / deleteCueIds edit existing ones by ID (batch, all-or-nothing). Cue time is fixed at creation — the Ableton API cannot move a cue; delete and re-add instead. Returns minted IDs for added cues.

**Parameters:** `tempo?`, `addCues?`, `renameCues?`, `deleteCueIds?`

## create_tracks

Create and/or duplicate tracks in a single undo step. Each spec needs EXACTLY ONE of type or duplicateOf: {type: "midi" | "audio", name?} (new empty track) OR {duplicateOf: trackId, name?} (full copy — clips, devices, mixer — inserted right after the source). Because each copy lands right after the SOURCE, N duplicates of the same track end up in reverse order (the last one created sits closest to the source), matching Live. Returns the created track summaries with IDs.

**Parameters:** `tracks`

## update_track

Rename, mute, solo or arm a track. Returns the updated summary.

**Parameters:** `trackId`, `name?`, `muted?`, `soloed?`, `armed?`

## delete_tracks

Delete tracks by ID in one undo step. All IDs are validated first: if any is stale the call fails and nothing is deleted.

**Parameters:** `trackIds`

## create_scenes

Append N empty scenes (count 1-64), or duplicate an existing scene and its clips (duplicateOf, inserted right after the source; count copies N times). Each copy lands right after the SOURCE, so count > 1 yields the copies in reverse order (the last one created sits closest to the source), matching Live. Returns the created scenes with IDs.

**Parameters:** `count?`, `duplicateOf?`

## update_scene

Rename a scene, in one undo step.

**Parameters:** `sceneId`, `name`

## delete_scenes

Delete scenes by ID in one undo step — this also deletes every session clip in those scenes. All IDs are validated first (all-or-nothing).

**Parameters:** `sceneIds`

## create_midi_clip

Create a MIDI clip in a session slot (trackId + sceneId) with notes inline, in one undo step. Each note is a tuple [pitch 0-127, startBeat, durationBeats, velocity 1-127] with an optional 5th element {prob?, velDev?, muted?, relVel?} for non-default extras.

**Parameters:** `trackId`, `sceneId`, `lengthBeats`, `notes`, `name?`

## replace_clip_notes

Replace ALL notes of a MIDI clip in one undo step. For partial edits prefer edit_clip_notes. Each note is a tuple [pitch 0-127, startBeat, durationBeats, velocity 1-127] with an optional 5th element {prob?, velDev?, muted?, relVel?} for non-default extras.

**Parameters:** `clipId`, `notes`

## create_audio_clip

Create an audio clip from a file path in a session slot (audio tracks only), in one undo step. The file must be accessible to Ableton Live.

**Parameters:** `trackId`, `sceneId`, `filePath`, `name?`

## update_clip

Update clip properties in one undo step: name, looping, color ("#RRGGBB"); for audio clips also warping (on/off) and warpMode (beats | tones | texture | repitch | complex | complexPro). Returns the updated clip summary.

**Parameters:** `clipId`, `name?`, `looping?`, `color?`, `warping?`, `warpMode?`

## delete_clips

Delete clips by ID in one undo step. All IDs are validated first: if any is stale the call fails and nothing is deleted.

**Parameters:** `clipIds`

## edit_clip_notes

Edit a MIDI clip's notes by filter, in one undo step — cheaper than resending all notes. select: {pitchMin?, pitchMax?, startBeat? (inclusive), endBeat? (exclusive)} — omitted bounds are open. Then EITHER remove: true (delete selected notes) OR transform: {transpose?, shiftBeats?, velocityDelta?} (applied to selected notes; results clamped to valid ranges), and/or add new notes. Each note is a tuple [pitch 0-127, startBeat, durationBeats, velocity 1-127] with an optional 5th element {prob?, velDev?, muted?, relVel?} for non-default extras. Returns {clipId, noteCount}; call get_clip for the full note list.

**Parameters:** `clipId`, `select?`, `remove?`, `transform?`, `add?`

## get_device

Full detail of one device: every parameter with name, current value, min/max, and quantized value labels. Use the deviceId from get_track or insert_device.

**Parameters:** `deviceId`

## insert_device

Insert a built-in Live device by name (e.g. "Reverb", "Auto Filter") onto a track's device chain, OR duplicate an existing device (duplicateOf: deviceId — the copy lands right after the SOURCE, so repeating the call on the same source stacks the copies in reverse order; trackId/index must be omitted). One undo step. Optional index positions a named insert (0 = first); omitted appends. Third-party plugins are not supported by the Ableton API. Returns the new device with its parameters.

**Parameters:** `trackId?`, `device?`, `duplicateOf?`, `index?`

## set_device_params

Set one or more parameters of a device by name, in one undo step. Values are Live-internal raw values within each parameter's [min, max] from get_device. All values are validated before any is applied. Returns only the changed values; call get_device for the full state.

**Parameters:** `deviceId`, `params`

## delete_device

Remove a device from its track's chain, in one undo step.

**Parameters:** `deviceId`

## set_simpler_sample

Replace the sample loaded in a Simpler device with an audio file (absolute path on the machine running Live), in one undo step. Fails UNSUPPORTED on any other device type. Returns the loaded sample's path.

**Parameters:** `deviceId`, `filePath`

## set_mixer

Set volume, pan and/or send levels for one or more tracks in ONE undo step. Values are Live-internal raw values: volume 0..1 (0.85 = 0 dB), pan -1..1, sends 0..1 (returnIds from get_set). Everything is validated before anything is applied — one bad entry means nothing changes.

**Parameters:** `updates`
